# Debian 13 (trixie) Port Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** KoBox installs and runs on Debian 13 (trixie) instead of Debian 12 (bookworm).

**Architecture:** One target, not two: Debian 12 left regular security support in June 2026, so KoBox
moves to trixie and stops accepting bookworm. Every release-specific fact (version id, codename,
PHP version) lives in one domain module, `src/domain/installation/platform.ts`; the preflight, the apt
sources, the PHP-FPM unit and its socket all derive from it. The E2E container moves to `debian:13`
and is the authority on what actually changed in the packages.

**Tech Stack:** TypeScript, vitest (unit/component/integration/E2E), Docker `debian:13` + systemd.

---

## What a `debian:13` container says (checked 2026-10-22)

| Package | trixie | Impact |
|---|---|---|
| `rtorrent` | 0.9.8 | none: same as bookworm, templates unchanged |
| `php-fpm` | 8.4 | unit and socket `php8.2-fpm` become `php8.4-fpm` |
| `nginx` | 1.26 | `listen … ssl http2` is deprecated, `http2 on;` exists since 1.25 |
| `bind9utils` | **absent** | the package is `bind9-utils`; the installer would fail on it |
| `dnscrypt-proxy` | 2.1.8 | back in Debian: the existing `isAvailable` branch now installs it |
| apt sources | deb822 | trixie ships `/etc/apt/sources.list.d/debian.sources`, no `sources.list` |
| openssh 10.0, easy-rsa 3.2.2, fail2ban 1.1.0, iptables 1.8.11 (nft), samba 4.22, postfix 3.10 | | validated by the E2E, fixed only where it fails |

Unchanged on purpose: `SUPPORTED_ARCHS`, the ext4 gate, every rtorrent template.

One commit per fix, `fix(<scope>): …`, each with its test.
